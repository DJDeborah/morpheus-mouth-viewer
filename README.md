# Morpheus 嘴部交互演示

**[打开 GitHub Pages 演示](https://djdeborah.github.io/morpheus-mouth-viewer/)**

免登录浏览 8 个口周输出点、独立区域控制、运动轨迹、整体上下唇连线及共同状态导出。无需安装软件或保持原电脑开机。

点击左侧“查看整口连线”，逐个选择区域调节；切换区域会保留已有输入。可“全部归零”，也可“导出当前状态”。

此公开仓库仅含网页运行所需且已公开的几何、轨迹、脚本和许可说明。完整原始 CAD、分析证据和复算代码位于所有者的[私有资料仓库](https://github.com/DJDeborah/morpheus-mouth-kinematics)。

连线为球心或嘴角盘体中心之间的几何折线，无力、无面皮，不代表真实唇缘。保留导向杆角与电机角的区别、未唯一确定的映射及原 CAD 重构限制。

来源为 [Morpheus-Hardware](https://github.com/ZZongzheng0918/Morpheus-Hardware)，详细来源、许可和限制见 [credits.html](credits.html)。
